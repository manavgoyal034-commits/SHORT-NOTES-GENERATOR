# AI Short Notes Generator 📝

An open-source desktop application that automatically converts any user-inputted topic into concise, structured study notes using OpenAI's GPT models.

---

## Features
- **Structured Synthesis**: Automatically organizes notes into an *Overview*, *Core Principles*, *Key Terminology*, and *Summary*.
- **Desktop GUI**: Clean UI built using Python's native `tkinter`.
- **Modular Design**: Extensible codebase separating engine logic from interface rendering.
- **Unit Tested**: Includes full test coverage for generator parameters and API integration.
